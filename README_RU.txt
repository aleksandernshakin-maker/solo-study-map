SOLO STUDY MAP — FINAL-R1

Это законченный автономный PWA-пакет для существующего GitHub Pages.
Все пользовательские данные остаются на вашем устройстве (IndexedDB); в GitHub попадает только код приложения.

ЗАГРУЗИТЕ В КОРЕНЬ РЕПОЗИТОРИЯ ВСЕ 9 ФАЙЛОВ:
- index.html
- style.css
- app.js
- layout-worker.js
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- README_RU.txt

Старые файлы изображений из v3 можно не удалять: новая версия их не использует.

ВАЖНО: до первого успешного запуска FINAL-R1 не удаляйте сайт/репозиторий и не очищайте данные браузера/PWA.
При первом запуске приложение автоматически ищет данные прежней версии в localStorage «solo-study-map-v2» и переносит уроки, темы, статусы, монстров и вложенность в новую IndexedDB. Исходный localStorage не удаляется и остаётся страховочной копией.

После Commit GitHub Pages обновится автоматически. Если установленное PWA всё ещё показывает старую версию, полностью закройте PWA/вкладку и откройте снова. В «Настройки» должна отображаться версия FINAL-R1 · 2026.09.13.

После первого успешного запуска рекомендуется:
1. Настройки → «Защитить хранилище».
2. Настройки → «Экспорт .ssmbackup» и сохранить резервную копию.
