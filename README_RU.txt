КАК ОБНОВИТЬ НА GITHUB:
1. В репозитории solo-study-map открой Add file -> Upload files.
2. Загрузи ВСЕ файлы из этой папки.
3. GitHub предложит заменить существующие index.html, sw.js, manifest.webmanifest и иконки — это нормально.
4. Commit changes.
5. GitHub Pages уже включён, поэтому новый deploy запустится автоматически.
6. Через 1–3 минуты открой приложение и обнови страницу. Если старая версия всё ещё видна, полностью закрой установленную PWA и открой снова.
